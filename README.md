# 📊 Super Store Sales & Product Analysis Dashboard

## 📌 Project Overview

This project presents an **interactive Power BI dashboard** designed to analyze and monitor Super Store business performance through sales, profit, quantity, products, discounts, and product-level analysis.

The dashboard transforms raw sales data into an interactive business intelligence solution that helps users understand **overall performance, product performance, trends, profitability, and the potential impact of different scenarios**.

The project focuses not only on reporting historical performance but also on supporting **data-driven decision-making** through interactive filters, product analysis, What-If analysis, and a decomposition tree.

---

## 🎯 Project Objectives

The main objectives of this dashboard are to:

- Analyze overall sales performance.
- Monitor total sales, profit, quantity, and discounts.
- Identify sales trends over time.
- Analyze performance across different product categories.
- Evaluate product-level sales performance.
- Compare products and categories.
- Understand the relationship between sales-related metrics.
- Analyze business performance using interactive filters.
- Perform What-If analysis to evaluate potential changes in business performance.
- Identify factors contributing to sales performance.
- Provide an intuitive and interactive business reporting experience.

The cover page provides a simple navigation interface to the main sections of the dashboard.

- 📈 Sales Overview

# 📈 2. Sales Overview

The **Sales Overview** page provides a high-level view of the company's overall performance.

### Key Performance Indicators

The dashboard includes important KPIs such as:

- 💰 **Total Sales**
- 📦 **Total Quantity**
- 💵 **Total Profit**
- 🏷️ **Average Discount**

These KPIs provide a quick snapshot of business performance.

### Analysis Included

The page provides several visualizations for analyzing:

- Sales distribution by category.
- Sales trends over time.
- Performance comparison between different business segments.
- Sales and performance patterns across selected dimensions.
- Yearly and period-based performance.

### Interactive Filters

Users can dynamically filter the dashboard using slicers, allowing them to analyze performance based on selected business dimensions.

This makes it possible to move from a general business overview to more specific analysis.

---

# 📦 3. Product Analysis

The **Product Analysis** page focuses on detailed product performance.

### Key Performance Indicators

The page includes:

- 💰 **Total Sales**
- 📦 **Total Quantity**
- 🛍️ **Total Products**
- 💵 **Average Selling Price**

These metrics help evaluate the performance and scale of the product portfolio.

### Product Analysis

The page provides visualizations for analyzing:

- Product sales performance.
- Product quantity performance.
- Category-level performance.
- Product-level contribution.
- Relationship between product-related metrics.
- Top-performing products.

A scatter chart is also used to explore relationships between business metrics and identify product/category performance patterns.

### Product-Level Insights

The product analysis helps answer questions such as:

- Which products generate the highest sales?
- Which categories perform best?
- Which products contribute significantly to total performance?
- How does selling price relate to product performance?
- Which products may require further investigation?

---

# 🔮 4. What-If Analysis

The **What-If Analysis** page introduces scenario-based analysis to evaluate potential changes in business performance.

### Current Performance

The page displays:

- **Total Sales**
- **Total Profit**

### Scenario Performance

It also calculates scenario-based values such as:

- **Total Sales - IF**
- **Total Profit - IF**

Users can modify the scenario assumptions through interactive controls and observe how the expected results change.

### Purpose

This functionality allows users to explore questions such as:

> "What could happen to sales and profit if a specific business assumption changes?"

This makes the dashboard more useful for **planning and decision support**, rather than only historical reporting.

---

# 🧩 5. Decomposition / Root Cause Analysis

The **Why Analysis** page uses a **Decomposition Tree** to investigate sales performance.

Instead of only showing the final sales number, the decomposition tree allows users to break sales down into different dimensions and investigate possible drivers of performance.

For example, users can analyze sales according to dimensions such as:

- Region
- Category
- Other available business dimensions

This supports a more detailed **root-cause analysis** approach.

### Business Question

The analysis helps answer:

> "Why is sales performance at this level?"

This allows users to move from **What happened?** to **Why did it happen?**
